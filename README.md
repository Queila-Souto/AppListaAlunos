## 🎯 Visão do Produto

O **AppListaAlunos** é um aplicativo Android desenvolvido com foco educacional 📚 — criado para que eu pudesse estudar e praticar conceitos essenciais do desenvolvimento Android, como:

- Consumo de APIs REST com **Retrofit**
- Manipulação de dados utilizando **Gson**
- Componentes visuais do **Material Design**
- Navegação, listas e ciclo de vida de Activities
  
O objetivo principal do app é permitir o gerenciamento de uma **lista de alunos**, oferecendo operações de:

- Visualizar alunos
- Adicionar novos alunos
- Editar informações
- Remover alunos

Tudo de forma prática, simples e intuitiva. 🚀


## 🔗 Integração com API Externa

Este aplicativo consome uma API REST desenvolvida por mim em Java utilizando **Spring Boot**, responsável por toda a persistência e lógica de dados.

🗂️ Você pode acessar o repositório da API aqui:
👉 [Repos API Java](https://github.com/Queila-Souto/ApiListaAlunos)

🌐 A API está disponível publicamente em:
👉 [API Publicada](https://apilistaalunos.azurewebsites.net)
